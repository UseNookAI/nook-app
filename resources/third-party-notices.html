Third-party notices

For Nook 0.3  ·  Updated 22 September 2026

Nook is built on open-source software and ships with open-source fonts and a Java runtime. This page names them and their licences. The full licence texts are in the runtime/legal folder next to the application for the Java runtime, and in each project's repository for the rest; the short licences are reproduced at the end of this page. Nothing here changes the licence of Nook itself, which is in the Nook software licence.

Models

Models are downloaded from their publishers when you choose them, each under the publisher's own licence, named on the model's card before you download it and on the page it comes from. Some licences restrict commercial use or ask for attribution (the Llama 3.1 community licence, the Stability AI community licence for SD Turbo and SDXL Turbo); it is your use, so it is your licence to keep.

  • multilingual-e5-small — Copyright (c) 2023 Microsoft (Liang Wang, Nan Yang and others). MIT License. The Nooklet finder: it reads a request in any language and picks the Nooklet for it. Downloaded on first use, in the GGUF conversion by TwinSuns LLC. huggingface.co/intfloat/multilingual-e5-small
